## Aperçu

Une ou deux phrases sur ce que fait la config (logo ASCII/pixel art, couleurs, modules affichés).

## Prérequis

- [fastfetch](https://github.com/fastfetch-cli/fastfetch)
- Un terminal qui gère les images (kitty, par exemple)
- Une Nerd Font (si tu utilises des icônes)

## Installation

```bash
git clone https://github.com/AEKO-kl/Ellen-fastfetch.git
cd Ellen-fastfetch
cp config.jsonc ~/.config/fastfetch/config.jsonc
cp -r logo ~/.config/fastfetch/
```

## Utilisation

```bash
fastfetch
```
